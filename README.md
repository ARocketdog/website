# arocketdog.au

Personal website for Brendan Chow. Plain HTML and CSS, no build step.

- Edit content in `index.html`, styles in `style.css`.
- Preview locally: open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.
- Deploys on push to `main` via GitHub Pages (`.github/workflows/deploy.yml`) and/or Render (`render.yaml`).
